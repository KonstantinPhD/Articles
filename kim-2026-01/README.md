> ### 🚀 Обновление от 03.09.2026: Реализация устойчивых инвариантных структур

В репозиторий добавлена программная реализация (**"ModifiedKalman_2.py"** и **"ModifiedKalman_3.py"**) двух новых численно устойчивых модификаций адаптивного фильтра на основе информационного критерия Джеффриса. Изменения направлены на устранение эффекта «зажатия» динамического диапазона коэффициента усиления в окрестности границы стационарности ($a \to 1.0$).

#### Модификация 1: Масштабирование числителя ($2\hat{\sigma}^2$)
* **Суть:** Компенсирует эффект автокорреляционного «удвоения» сигнальной компоненты в знаменателе измерительного тракта ($T \approx \hat{\sigma}^2 + \sigma_\nu^2 + P_t$).
* **Результат:** Формула принимает вид $K_t = 2\hat{\sigma}^2 / (T + \hat{\sigma}^2)$. Это гарантирует полное восстановление динамического диапазона пропускания контура ($K \in [0, 1]$) без деструктивных операций вычитания ковариаций, исключая деление на ноль.

#### Модификация 2: Регуляризованное разделение подпространств
* **Суть:** Использование оператора модуля для формирования модифицированной оценки полной дисперсии наблюдений: $T_{\text{mod}} = \vert T_t - \hat{\sigma}_t^2 \vert$.
* **Результат:** Выступает в роли «вычислительного предохранителя». Полностью блокирует потерю положительной определенности ковариационной матрицы из-за случайных локальных стохастических флуктуаций на малых выборках. 

*Оба алгоритма обеспечивают безусловную численную устойчивость на ЭВМ, формируют эмпирически несмещенные оценки и переводят невязку фильтрации в состояние стационарного белого шума без априорного знания ковариационных матриц шумов $Q$ и $R$.*

## 📌 Описание проекта
Моделирование и анализ дискретного фильтра Калмана первого порядка для процесса случайного блуждания с адаптивной оценкой ковариаций шумов.

## 🎯 Цели исследования
- Верификация математического аппарата фильтра Калмана
- Анализ сходимости коэффициента усиления в установившемся режиме
- Валидация теоретических значений дисперсий ошибок оценивания
- Исследование адаптивных свойств алгоритма при неизвестных статистиках шумов

## 📊 Основные результаты
- Коэффициент усиления фильтра сходится к теоретическому значению: **0.80** (при Q=16, R=4)
- Дисперсия ошибки оценивания состояния: **8.0** (теоретическое P∞)
- Дисперсия инновационной последовательности: **12.0** (теоретическое F∞)
- Автокорреляция невязок соответствует белому шуму
